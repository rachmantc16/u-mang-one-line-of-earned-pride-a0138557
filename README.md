A tiny, deterministic program for make.fun's "One Line of Earned Pride" bounty. It writes a single line — a quiet moment of pride earned the hard way, three months after a stroke, in one signature on a grandson's birthday card — to `entry.txt` in the output directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). No input, no randomness: the same line every run.

## Run it

```sh
node main.ts
```
